# Layaw PDF marketing site

`index.html` is the whole site: one self-contained file, with the Layaw PDF logo embedded inline.

- Libraries are pinned from cdnjs: GSAP 3.12.5, ScrollTrigger 3.12.5, three.js r128.
- Fonts come from Google Fonts. Red Hat Display, Text and Mono stand in for Gotham. The font catalog specimen also loads the 16 families the app embeds, subset to only the letters it shows.
- To preview it, open `index.html` in a browser or serve the folder (`npx serve layaw-pdf-site`).
