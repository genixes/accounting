# Awesome Design (brand design systems)

Each brand folder holds a `DESIGN.md` with that brand's visual language: palette, type scale, spacing, components, motion and do/don'ts. Source: [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) (MIT).

## How to use

1. Pick the brand(s) closest to the requested feel from the index below. If the user named none, suggest 2–3 that fit and say why.
2. Read only the chosen `DESIGN.md` files (they are long; don't load them all).
3. Turn the spec into design tokens (CSS variables / Tailwind theme) before writing components, then build against those tokens.
4. Borrow the *system* (rhythm, contrast, type, restraint), not logos, product names or trademarked assets.
